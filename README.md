# pr3

Программа решает четыре задачи на указатели. Каждая задача читает свои данные с клавиатуры и печатает результат.

## Задачи

1. Считываются два целых числа `a` и `b`. Указатели направляются на эти переменные. Через указатель `a` увеличивается в 2 раза, `b` делится на 2 нацело.
2. Для трёх указателей на `float` выделяется динамическая память. В ячейки записываются значения `1.5`, `4.25` и `-2`. Затем меняются местами значения первых двух переменных.
3. Создаётся динамический массив `a` длины `n`. Программа печатает номера отрицательных элементов, начиная с 1, и их среднее арифметическое.
4. Создаётся динамический массив `b` длины `n`. В массив `c` попадают только корни квадратные из положительных элементов, делённые на 5. Пустых элементов внутри нет. Массив `c` сортируется по возрастанию методом выбора и перестановки.

## Сборка

Нужны CMake, GCC и Make. Каталог `.build` в репозиторий не входит.

```bash
mkdir -p .build
cd .build
cmake ..
make
```

Запуск из корня проекта: `./.build/pr3`.

## Пример ввода

```text
10 7
5
1 -2 3 -4 0
4
16 1 -4 9
```

Для этого ввода программа выводит `a = 20`, `b = 3`, обмен `4.25 1.50 -2.00`, номера `2 4` со средним `-3.0000` и отсортированный массив `c`: `0.2000 0.6000 0.8000`.
